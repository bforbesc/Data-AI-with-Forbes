# Data & AI with Forbes

Teaching notebooks for data and AI, clearly and simply explained. Each notebook runs in Google Colab and illustrates one idea hands-on, for students, professionals and anyone curious. Some come with a LinkedIn article; follow along on [LinkedIn](https://www.linkedin.com/in/bernardoforbescosta/) and watch this repo for new material.

1. **Open a notebook in Colab** from the table and run the cells from top to bottom.
