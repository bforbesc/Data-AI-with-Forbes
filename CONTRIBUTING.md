# Contributing

Thanks for helping make Data & AI with Forbes useful to learners.

## Questions and fixes

[Open an issue](https://github.com/bforbesc/Data-AI-with-Forbes/issues) for a question, broken link, factual correction, or topic suggestion. Include the notebook or project link and enough detail to reproduce the problem.

## Add learning content

1. Keep notebooks in `notebooks/`, with a short explanation of the idea, prerequisites, and how to run them. Make paid API or special runtime requirements visible.
2. Add an entry to the learning notebook table in the root README. Check the Colab link and any companion article link.
3. Use synthetic or appropriately licensed public data, with attribution. Keep API keys and personal data out of commits and notebook outputs.

## Add a project or historical experiment

1. Use [the project template](projects/TEMPLATE.md) as a writing guide. Add a section to [the project catalogue](projects/README.md), or create a separate project story if more detail is needed.
2. Link to the original code and acknowledge collaborators and upstream templates. The catalogue centralizes discovery; each project repository remains the source for its implementation.
3. Describe what someone can learn from the experiment. Distinguish observed behavior from proposed exercises and future improvements.
4. Label historical context and deployment availability honestly. Do not invent dates or imply that an untested hosted app is working.
5. Add the project to the root README and check relative links and section anchors.

Submit changes in a pull request with a brief explanation and the checks you performed. Linked projects keep their own licenses; this repository's license does not replace them.
