## Start with what you need

| If you want to… | Try… |
|---|---|
| Get an accessible introduction to an AI topic | Browse the beginner options in [DeepLearning.AI's course catalogue](https://www.deeplearning.ai/courses) |
| Understand the mathematics behind language models visually | Watch a video from [my curated LLM maths playlist](https://www.youtube.com/watch?v=AsNTP8Kwu80&list=PLYhRPCyrSUlpqhQZ8xG1Lqo-Oy8UyOI7Y) |

| Think more deeply about building and evaluating AI applications | Read [AI Engineering](https://www.oreilly.com/library/view/ai-engineering/9781098166298/) by Chip Huyen |

| Read about my own experiments and decisions | Browse [my articles](#my-articles) below |

You do not need to work through everything. Pick one question, explore one resource, and connect it to a small example you can explain or check.

## Books

### AI Engineering — Chip Huyen

[Read the publisher's page →](https://www.oreilly.com/library/view/ai-engineering/9781098166298/)

A reference for building applications with foundation models: choosing an approach, evaluating results, working with prompts and retrieval, using agents, and understanding the trade-offs around deployment.

**Where it fits:** a deeper reference after your first examples. The publisher describes it as intermediate to advanced, so beginners can start with the introduction and return to individual chapters as the ideas become familiar. Full access is through the publisher's book or learning platform.

**Connect it to the hub:** after the [GenAI course](../notebooks/genai-day/), ask how you would evaluate a hotel assistant before using it. After [Data Wrestler](https://github.com/bforbesc/Your-Data-Wrestler), ask which answers can be checked directly against the data.

| [DeepLearning.AI courses](https://www.deeplearning.ai/courses) | Foundational programmes and focused short courses across AI topics | Use the level and prerequisite descriptions to find a suitable starting point. A course about a tool is a chance to understand the broader idea it demonstrates. |

## Newsletters

| Resource | What it's useful for | A small learning habit |
|---|---|---|
| [The Batch — DeepLearning.AI](https://www.deeplearning.ai/the-batch/) | AI news, research, applications, and commentary in a weekly newsletter | Pick one item and explain the underlying idea in your own words. |
